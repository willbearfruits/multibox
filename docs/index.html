What it does

One mouse & keyboard

Shove the cursor off a screen edge and you're typing on the machine seated there (lan-mouse, TLS-fingerprint paired).

One clipboard

Copy anywhere, paste anywhere — text and screenshots. Pause it with one toggle before copying secrets.

Laptops as extra monitors

Toggle a side and that laptop becomes a real Hyprland output: drag windows onto it, GPU-streamed at 60 fps, view-only VNC by default.

Drag & drop files

Drop files on a machine's row in the bar widget (or the Dropzone window) and they land in its ~/Drop/incoming.

~/Drop everywhere

A syncthing-mirrored folder shared by the whole fleet — drop a file on one machine, it's on all of them.

Omarchy-native controls

A bar widget with live fleet health and quick actions, plus a libadwaita setup window where you drag machines into their real seats.

Install

# on every machine (needs a Tailscale tailnet):
$ git clone https://github.com/willbearfruits/multibox
$ cd multibox && ./install.sh
# then, once all machines are installed:
$ multibox pair
# just the Omarchy bar widget:
$ omarchy plugin add https://github.com/willbearfruits/multibox --enable

Design

  • Everything binds only to the machine's tailscale IP and rejects non-fleet peers — the LAN sees nothing.
  • One fleet description (machines.json) generates every config; multibox apply keeps machines in agreement.
  • Window "dragging" is honest: windows render on a remote screen (they can't migrate processes) — and it feels like one desktop anyway.
  • ~500 lines of Python, bash, and QML. No cloud, no accounts, no daemons you can't read in one sitting.
